# 设计系统

## 令牌

- `site/src/styles/tokens.css`：与视觉方向无关的尺度——间距（4px 基准）、字号阶梯（大字号流式）、圆角、
  动效时长与缓动（含回弹曲线）、层级、布局宽度、属性 / 异常 / 锐利度颜色。`prefers-reduced-motion` 下时长归零。
- 语义颜色由各方向在 `[data-direction][data-theme]` 上赋值：`--c-bg`、`--c-surface*`、`--c-line*`、`--c-text*`、
  `--c-accent*`、`--c-focus`；字体：`--font-display`、`--font-body`、`--font-num`。组件只引用语义令牌。
- `site/src/styles/base.css`：重置、焦点环、`.deco-slot` 等跨方向基础件；切换主题时给 `html` 临时加
  `theme-switching`，颜色在 360ms 内平滑过渡，不突兀跳变。

## 主题

`ThemeScript` 在首屏绘制前读取偏好（`localStorage: mhdb-theme` = `system` / `light` / `dark`），写入
`html[data-theme]`，避免闪烁；「跟随系统」时监听系统切换。`ThemeToggle` 是三态单选按钮组。

## 视觉方向

**已选定（2026-10-14）：外层框架用 B「导虫」。** A、C 稿保留在 `/design/` 下作参考。

### 三个方向的静态稿

| 方向 | 页面 | 要点 |
|---|---|---|
| A 调查手记 | `/design/a/`、`/design/a/builder/` | 纸与墨、朱砂强调；思源宋体标题、霞鹜文楷批注、Fraunces 数字；细墨线分隔、标本卡、印章 |
| B 导虫 | `/design/b/`、`/design/b/builder/` | 深色优先工具台；导虫萤绿唯一发光色；Martian Mono 数字；网格、刻线；首页导虫群（Canvas） |
| C 地脉 | `/design/c/`、`/design/c/builder/` | 磨砂分层、程序生成等高线；`--accent` 注册为颜色属性，随地区 / 怪物平滑换色；得意黑（子集改名 MHDB Display）标题 |

选择器（武器、防具、饰品等）统一要求：带搜索（拼音 / 首字母 / 繁简 / 日英）、键盘可操作、展开收起有动画、
手机上为底部抽屉。

## 配装器与装备类界面（用户要求，2026-10-14）

无论最终选哪个方向，配装器和装备相关界面要**贴近游戏 UI**，「样子要对」，不要求一模一样：

- 使用从游戏 UI 图集转换出的图标：装备类型图标（按稀有度着色）、饰品（珠子）图标、镶嵌槽图标、技能图标、
  武器客制图标等。
- 布局参考游戏的装备 / 饰品界面：每件装备一行，右侧列出它的镶嵌槽与已镶饰品（饰品图标 + 名称 +【等级】），
  装备详情面板（攻击、锐利度、会心、属性、龙封力、镶嵌槽……），技能等级以格子显示。
- 站点自己的视觉方向只负责外层框架（导航、面板容器、字体、颜色主题）。
- 用户选定：用游戏图标与游戏布局，**边框、底纹由我们自己绘制**，不使用游戏界面的边框装饰贴图。
